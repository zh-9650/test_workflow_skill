# 测试流程契约

完整流程：资料读取 → 模块化业务理解 → AI 自审 → 人工确认 → 测试点 → AI 自审 → 人工确认 → 测试用例 → AI 自审 → 人工确认 → 执行规划 → AI 自审 → 人工确认 → 当前 Batch 数据准备 → Batch 执行 → Worker 自审 → 独立 Reviewer → 缺陷/回归 → 最终结果复核。

状态恢复只保证到 Batch/Case，不保证 UI 点击级恢复。所有用户可见语言使用正常测试术语，不使用 Gate、Lease、Control Plane、COMPLIANT 等框架术语。

阶段完成必须同时满足：正式产物位于当前 Run、文件摘要仍与登记一致、对应自审已通过、需要人工确认的产物已确认。`run-status.json` 中的布尔字段只是显示投影，不能代替产物登记。最终关闭必须引用经过 `test-result-review` 校验的结果文件。
